# CIFAR-10 Image Classification Pipeline

A deep learning computer vision project built to train, evaluate, and test image classification models using the CIFAR-10 dataset.

## 🧠 Project Overview
This repository implements a convolutional neural network workflow to classify images across 10 distinct object categories from the CIFAR-10 dataset. The project explores model training, performance evaluation, and real-world inference generalization.

## 🛠️ My Contributions & Workflow
* Developed and structured the model training and evaluation scripts using Python.
* Implemented data loading, preprocessing, and model inference pipelines.
* Utilized modern AI-augmented development workflows to accelerate code structuring, debugging, and optimization.

## 📊 Model Performance & Findings
* **Baseline Performance:** The model achieved standard benchmark accuracy on the clean, low-resolution (32x32) CIFAR-10 test set.
* **Real-World Generalization:** When tested on custom, unconstrained real-world photographs taken outside the curated dataset distribution, model performance highlighted known domain-gap challenges, demonstrating weaker inference on high-resolution photos with complex backgrounds. This provided practical insights into data preprocessing, augmentation needs, and domain adaptation in computer vision.
